# Banking Management System

A simple Banking Management System built using Python Object-Oriented Programming (OOP).

## Description

This project demonstrates how Python classes and objects can be used to create a simple banking application.

Each bank account contains:

- Account holder name
- Account number
- Balance

The application supports:

- Deposit money
- Withdraw money
- Check balance
- Display account details
- Change the bank name
- Track total number of bank accounts

## OOP Concepts Covered

- Class
- Objects
- `__init__()`
- `self`
- Instance attributes
- Instance methods
- Class variables
- Class methods
- Validation
- Modules
